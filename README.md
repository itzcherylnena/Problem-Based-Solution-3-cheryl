 💧 Silent Thirst Tracker

Silent Thirst Tracker is a simple hydration tracking web app built using **HTML, CSS, and JavaScript**.  
It helps users monitor their daily water intake, stay hydrated, and build healthy drinking habits.

---

🌟 Features

- ✅ Track daily water intake
- ✅ Set and edit hydration goals
- ✅ Quick-add water buttons (250ml / 500ml)
- ✅ Circular progress tracker
- ✅ Remaining water calculation
- ✅ Water intake history
- ✅ Hydration tips section
- ✅ Data saved using Local Storage
- ✅ Reset progress anytime

---

 🕹️ How to Use

1. Open the app in your browser.
2. Set your daily hydration goal using the **Edit Goal** button.
3. Click the **250 ml** or **500 ml** buttons to add water intake.
4. Watch the progress circle update automatically.
5. Check your recent intake history in the **Recent Intake** section.
6. Use the **Reset** button to clear your daily progress.
